# General ML Topics — An Interactive Machine-Learning Textbook

A complete, self-contained interactive textbook covering machine learning from first
principles to practice, in a single web page.

**Read it here: <https://metaphorpritam.github.io/General_ML_Topics/>**

## What's inside

- **22 chapters** in one continuous arc: learning theory → linear models → logistic
  regression & GLMs → optimization → evaluation → generalisation & regularisation →
  PAC/VC → KNN → probabilistic methods → trees → bagging & random forests → AdaBoost →
  gradient boosting & the XGBoost family → imbalanced data & explainability → neural
  networks & backpropagation → deep architectures → SVMs → PCA → clustering (two
  chapters) → a model-selection playbook → a timed coding-test drill chapter.
- **Step-by-step derivations** with matrix/tensor shapes annotated at every step.
- **Worked numerical examples** — every number recomputed programmatically and verified.
- **140+ figures**: architecture diagrams, computation graphs, decision flowcharts.
- **6 interactive labs**: gradient-descent on a loss surface, ROC threshold explorer,
  activation playground, convolution arithmetic explorer, attention-weight visualizer,
  k-means stepper.
- **250+ collapsible blocks**: practice questions with hidden solutions, and
  coding labs (scikit-learn / numpy / pandas) with interview-style notes.
- **Dark mode**, scrollable filterable table of contents, fully client-side.

## Usage

Open the page and read top-to-bottom, or jump around via the sidebar. Everything runs
in the browser — the only external dependency is the MathJax CDN for math rendering.

## Structure

```
docs/

```

## Question Bank

Practice companion: **[the Question Bank](https://metaphorpritam.github.io/General_ML_Topics/test_set.html)** — 128 MCQs (instant feedback, worked explanations, score tracking) + 50 coding problems checked live in your browser via PyScript, with three progressive hints each. Over half the set drills probability, Bayes' theorem and statistics; includes business-application bands (credit risk, A/B testing, churn/CLV).
